# CC342 — DAS website materials guide

Replace the root `index.html` with the supplied updated file **once**. Keep existing `announcements.md` and `instructor.md` unchanged.

For each week, upload PDF files into:

- `materials/week01/slides/` — Lecture Slides
- `materials/week01/notes/` — Detailed Notes
- `materials/week01/extra/` — Additional Materials

Repeat for `week02` through `week16`. PDF filenames can be anything.

In GitHub, create a subfolder by selecting **Add file → Create new file**, typing `materials/week01/slides/README.md`, then committing. Repeat for the other categories or weeks as needed. Upload PDFs into the relevant folders via **Add file → Upload files**.

**Important:** If you have previously uploaded PDFs directly under `materials/week01/`, move those PDFs into one of the three subfolders, otherwise they will not appear. Do not upload copyrighted resources unless you have permission. The website lists PDFs using the public GitHub API; availability and cache updates may be delayed.
